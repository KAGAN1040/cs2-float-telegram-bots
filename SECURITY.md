# Güvenlik / Security

Bu repo hiçbir kullanıcı hesabını, API anahtarını veya Telegram tokenini içermez.

- Kendi bilgilerini **yalnızca yerel `.env`** dosyasına gir.
- `.env`, `sent_ids.json` ve eski `gonderilen_ilanlar.json` dosyalarını herkese açık depoya ekleme.
- Telegram tokenin veya Empire API key'in bir yerde açığa çıktıysa **derhal iptal et/yenile**. Git commit geçmişini temizlemek veya dosyayı silmek yeterli değildir.
- Bot yalnızca ilanları kontrol edip Telegram'a bildirim gönderir; satın alma izni gerektirmez ve istemez.
- Kod üçüncü taraf sitelerden veri alır. Servislerdeki değişiklikleri, hizmet koşullarını ve hız limitlerini dikkate al.

Güvenlik sorunu bildirmek istersen bir GitHub issue açarken **gizli anahtar, kişisel bilgi veya gerçek token ekleme**. Hesap gizliliğini riske atan konularda özel raporlama kanalı kullan.
